*This is a website dedicated to music, creativity, friendships, and the memories of my very first YSWS.*
Aria was my first YSWS, and it became so much more than just a program to me. It was a place where I explored, experimented, created things, discovered music, and made memories that I wanted to hold on to.
This website is my little time capsule for that experience. Every page has something to tell, every track has a place, and every little detail carries a piece of the journey.
